# ดาวน์โหลด 0JAY Moonlight

โปรแกรมสำหรับเล่นเครื่องที่เช่าจากร้าน **0JAY** บน Windows

## ⬇️ ดาวน์โหลด

**[0JAY-Moonlight-Setup-1.0.4.exe](https://github.com/fbpinote-svg/0jay-moonlight-download/releases/download/v1.0.4/0JAY-Moonlight-Setup-1.0.4.exe)** (25 MB)

เวอร์ชันทั้งหมด: [Releases](https://github.com/fbpinote-svg/0jay-moonlight-download/releases)

## ต้องมี

- Windows 10 หรือ 11 แบบ 64 บิต
- การ์ดจอที่ถอดรหัสวิดีโอได้ (การ์ดจอทั่วไปในรอบหลายปีนี้ได้หมด)
- อินเทอร์เน็ต
- บัญชีของร้าน 0JAY — เช่าเครื่องได้ที่ [app.0jay-shop.com](https://app.0jay-shop.com)

## ติดตั้ง

1. ดับเบิลคลิก `0JAY-Moonlight-Setup-1.0.4.exe`
2. ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
3. กด ถัดไป ตามขั้นตอน (ยอมรับสัญญาอนุญาต → เลือกที่ติดตั้ง → ติดตั้ง)
4. ตัวติดตั้งจะ **ตรวจความพร้อมของเครื่อง** ให้: การ์ดจอ ลำโพง/หูฟัง ไมค์ สิทธิ์ใช้ไมค์ และการเชื่อมต่อร้าน
   ข้อไหนขึ้น "ควรแก้" หรือ "ต้องแก้" กดปุ่ม **แก้ไข** แล้วกด **ตรวจอีกครั้ง**
5. กด เสร็จ — โปรแกรมเปิดขึ้นมา และมีไอคอนบนเดสก์ท็อป

## ใช้งาน

1. เข้าสู่ระบบด้วยบัญชีเดียวกับเว็บ (อีเมล/ชื่อผู้ใช้ หรือ Google / Discord)
2. เติมเงิน: กดที่ **ยอดเงิน** บนแถบด้านบน → สแกน QR พร้อมเพย์ (หรือใช้ซองอั่งเปา TrueMoney)
   ถ้าโอนแล้วยอดไม่ขึ้น กด "โอนแล้วแต่ยอดยังไม่ขึ้น?" แล้วแนบสลิป
   ถ้ามีรายการที่สร้างไว้แต่ยังไม่โอน โปรแกรมจะพาไปเติมรายการนั้นก่อน (ปุ่ม "รอโอน" บนแถบด้านบน)
3. เช่าเครื่อง: กด **เช่าเครื่อง** → เลือกเครื่อง → เลือกจำนวนชั่วโมงหรือแพ็กเกจ → (เลือก Windows) → ยอมรับกฎร้าน → ยืนยันเช่า
   (เช่าที่เว็บก็ได้เหมือนเดิม เครื่องจะขึ้นในโปรแกรมเอง)
4. **คลิกขวาที่เครื่องที่เช่า**: "เริ่มเตรียมเครื่อง" ถ้าเครื่องยังไม่เปิด, สั่งเปิด / รีสตาร์ท / ปิดเครื่อง, ต่อเวลา, เปลี่ยน Windows, จบการเช่า
5. กดที่เครื่อง (หรือ "เข้าเล่นเกม") → โปรแกรมเชื่อมต่อให้เอง **ไม่ต้องใส่ PIN** → เลือก Desktop แล้วเล่นได้เลย
6. อยากใช้ไมค์: กดรูปเฟือง (ตั้งค่า) → การตั้งค่าเสียง → **"ระบบไมค์"** เลือกได้ทีละหนึ่งระบบ แล้วเลือก "ไมค์ที่ใช้"
   - **ระบบ 1 — ผ่านร้าน 0JAY:** บนเครื่องที่เช่า (ในเกม / Discord) เลือกไมค์ **"Parsec Virtual Audio"**
   - **ระบบ 2 — ในสตรีม Moonlight (แบบ Moonlight V+):** บนเครื่องปลายทางเลือกไมค์ **"Steam Streaming Microphone"**
     หรือ **"CABLE Output"** (ใช้ได้กับเครื่องที่ Sunshine รองรับไมค์)
7. เลือกลำโพงหรือหูฟังที่จะฟังเสียงได้ที่ช่อง "ลำโพง / หูฟัง" ในหน้าเดียวกัน

ออกจากการสตรีม: กด `Ctrl + Alt + Shift + Q`

## ถอนการติดตั้ง

Windows → Settings → Apps → **0JAY Moonlight** → Uninstall
